Your project roadmap

The work, step by step.

Each task opens on its introduction day. Your projects grow from individual pages into a working platform.

Available at the start Upcoming task Difficulty builds as you go
  1. 01DAY 1
    Available at the startBeginner

    Build the TechBridge Homepage

    Create the first version of the TechBridge website using HTML and CSS.

    What you'll build

    A clear, responsive homepage with structured content and CSS styling that introduces TechBridge and its work.

  2. 02DAY 4
    Upcoming · opens Day 4Beginner

    Build the TechBridge Programs Experience

    Create a Programs experience that presents TechBridge's available learning programs.

    What you'll build

    A dedicated programs page that explains the learning paths and helps visitors explore the options available to them.

  3. 03DAY 8
    Upcoming · opens Day 8Beginner → Intermediate

    Build the Internship Tasks Experience

    Create an interface that presents the internship tasks and helps users understand the journey.

    What you'll build

    A task roadmap that shows what interns will build, when each project begins, and how the work progresses.

  4. 04DAY 11
    Upcoming · opens Day 11Beginner → Intermediate

    Build an Interactive Task Tracker

    Use JavaScript to make the internship task experience interactive and track progress.

    What you'll build

    An interactive version of the task roadmap that lets interns record and view their progress across the projects.

  5. 05DAY 15
    Upcoming · opens Day 15Intermediate

    Build the Intern Registration Experience

    Create a professional registration and onboarding interface for TechBridge interns.

    What you'll build

    A polished registration flow with the information and interface an incoming intern needs to get started.

  6. 06DAY 19
    Upcoming · opens Day 19Intermediate

    Build the Task Submission System

    Create an interface through which interns can prepare and submit their task work.

    What you'll build

    A submission experience where interns can prepare their project work and send it in for review.

  7. 07DAY 22
    Upcoming · opens Day 22Intermediate → Advanced beginner

    Build the Intern Dashboard

    Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

    What you'll build

    A personal workspace that brings an intern's profile, task progress, and submitted work together in one view.

  8. 08DAY 26
    Upcoming · opens Day 26Advanced beginner

    Build the Complete TechBridge Internship Platform

    Combine the components created during the internship into a complete TechBridge platform.

    What you'll build

    Connect your homepage, programs, task tracker, registration, submissions, and dashboard into one cohesive experience.

✳ Day 30: step back and see how far your work has come.
